# Examples

Start with [scouts](scout-job.json), a [small implementation](job.json), or the
[Relay starter](relay/README.md). [Jobs](jobs.md) explains assignment composition.
Copy optional [agent definitions](agents/) into a discovery directory when needed.

New examples use shared workspaces and ordinary coordinator testing/review. Assign
responsibilities in task text, add workers to existing runs, and send follow-ups instead
of restarting completed work. Select worktrees explicitly for isolated experiments.

Choose approved models and credentials before paid execution. Setup and scripted harness
checks make no model calls. See [configuration](../docs/reference/config.md),
[tools](../docs/reference/tools.md), and [migration](../docs/reference/migration.md).
