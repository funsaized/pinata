# Replacement preservation coverage

This index maps the preservation contracts in [the rewrite plan](https://github.com/funsaized/pinata/blob/c426753291351c9b3b79a44c902cd5db17244c2a/docs/maintainers/rewrite-plan.md)
to executable replacement tests. Test names identify observable behavior, rather
than assuming that a similarly named module preserves a contract. The tests use
scripted providers, real local storage and supervised subprocesses; they do not
establish live coding quality. Milestone and platform results are recorded in
[rewrite progress](https://github.com/funsaized/pinata/blob/9a6d9de/docs/maintainers/rewrite-progress.md), [UI evidence](rewrite-ui.md) and
[benchmark evidence](rewrite-benchmarks.md).

Replacement tests retain their `rewrite-` filenames after the single package
cutover. Retired baseline characterizations and source are archived; the default
suite targets the replacement. Baseline report, batch, oracle and corpus bytes
remain historical evidence. Links into retired source resolve against the explicit
historical source inventory rather than requiring a live old engine.

F9 and F10 are observations, not additional reproduced correctness defects.
The [new benchmark evidence](rewrite-benchmarks.md) measures the actual dispatch,
history, projection, storage, UI and resource costs. A failed gate remains a failed
gate with its complete attempts retained; it cannot become a passing coverage row.

The old bounded-result presentation contract is exercised by
[tool page tests](../../test/engine/rewrite-pages.test.ts) and the actual registered
Pi status/page tools in `rewrite-pi-surface.test.ts`. Large Unicode/escaped results
reassemble byte-for-byte, remain tied to their first immutable response while live
state changes, and cannot expose unrelated artifacts through forged or expired
cursors. Full API replies remain intact. Dependency brief preservation is covered
separately by `rewrite-dependencies.test.ts`: list/result byte limits, advancing
offsets, exact frozen assignment scope and retained-artifact integrity. Complete
result JSON is accessible; referenced report/transcript contents are not exposed
by that tool. `rewrite-child-backends.test.ts` reconstructs a large child wait
result through the actual worker page tool on both backends at capacity two.

Recorded functional and installed-package checks pass for the source snapshots
identified in [rewrite progress](https://github.com/funsaized/pinata/blob/9a6d9de/docs/maintainers/rewrite-progress.md), including public exports,
packaged dependencies/schema resources and Pi/headless behavior. The public typed
API also passed through process and Herdr workers hosted by compiled Pi/Bun on
Linux. macOS evidence uses the pinned SDK and installed Pi 1.5 Node CLI; it does
not establish compiled Bun execution there.

The final scale/history matrix passed all 8,303 assignments across 35 measured
cells, with the owner selecting a 4,096-assignment cap. Four larger history cells
were explicitly omitted. The owner accepted separate Mac/APFS latency limits;
the required fresh Mac run passed all eight scenarios on their first attempts,
as did the final Linux run with unchanged default limits. The
[benchmark record](rewrite-benchmarks.md) records the
criteria, measured failures and final scope. Windows was deferred in that cutover cohort; the current platform guide records
the later Job Object coverage. Platform skips are never counted as successful execution.
