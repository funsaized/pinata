# Commands

In Pi: `/pinata status`, `/pinata runs`, `/pinata view`, `/pinata view --external`,
`/pinata mode lean`, `/pinata mode observe`, `/pinata gc`, `/pinata help`.

Terminal: `pinata agents`, `pinata run <job.json>`, `pinata resume <run>`,
`pinata logs <run> --follow`, `pinata view <run>`, `pinata integrate <run>`,
`pinata migrate <input> --output <new-file>`, and `pinata gc`.

Use [tools](tools.md) for dynamic addition, messages, follow-ups, waits and cancellation.
Legacy rerun/repair workflows are replaced by explicit follow-ups without descendant replay.
