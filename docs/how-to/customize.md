# Customize Pinata

```json
{ "workspace": "shared", "mode": "lean", "codemode": true, "setup": false }
```

Choose agent definitions, model defaults/fallbacks, tool providers, workspace preferences
and backend in [configuration](../reference/config.md). Assign instructions per worker
or run. Express strict project workflows through coordinator instructions and external CI.
Pinata has no production budget, ownership or review-policy configuration.
