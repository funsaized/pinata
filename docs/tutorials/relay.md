# Relay

Create the disposable starter:

```sh
node examples/relay/setup.mjs /tmp/relay-exercise
```

Choose approved models in the generated job and run `pinata run job.json`. The job
assigns complementary module responsibilities in the shared checkout, with ordinary
review workers. The coordinator owns acceptance and can run `node --test` and
`node verify.mjs`, inspect failures, continue workers or finish directly with coding tools.
Setup makes no model calls. Executing the job spends tokens. Scripted Relay regressions
validate harness behavior; they are not measurements of live coding quality.
